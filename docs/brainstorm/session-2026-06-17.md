## Idea Log

### #1 — First-run GUIDED TOUR at first login (both roles)
A product walkthrough / first-run experience that ORIENTS the user on first connection:
"where am I, what to do first, how my space works". NOT the existing admin setup wizard
(work days / hours / shift types) — that stays. This is a guided tour layer on top.
- **Employee**: tour of `/dashboard` space (own schedule, time tracking, absence requests).
  Today: zero onboarding — brutal redirect to `/dashboard`.
- **Admin**: tour of `/admin` space (planning, employees, constraints, billing), AFTER the
  existing setup wizard.
- Open questions to pin (→ aped-grill): coachmarks vs welcome-modal-checklist vs both;
  per-user completion flag (today only clinic-level `onboardingCompleted` exists — no
  per-user flag); skippable/replayable; library (driver.js / react-joyride / shepherd) vs
  custom; i18n FR/EN of tour copy.
