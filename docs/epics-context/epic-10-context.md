## Architecture references

- Patterns to respect:
  - **Data flow (NON-NEGOTIABLE):** `Page → Client Component → Hook → Zsa → Server Action → tRPC Client → NestJS API` (architecture Phase 2/3). No shortcuts; no direct DB access from `apps/web`.
  - **State split:** React Query (server state, via Zsa) + **Zustand for UI state only**.
  - **Zsa tuple:** `useServerActionMutation(..., { returnError: true }).mutateAsync()` returns `[data, err]` — destructure the tuple (see Lesson L1).
  - **Prisma 7.2 Schema Folders** in `apps/api/prisma/schema/`; `pnpm db:push` + `pnpm db:generate` from root. Json-column persistence precedent: `Clinic.onboardingDraft Json?`.
  - **Validation:** single source in `@pawly/validators` (`@pawly/zod` instance); shared by tRPC input + Zsa actions.
  - **tRPC:** routers in `apps/api/src/trpc/`, `{resource}.{action}` naming; `protectedProcedure = publicProcedure.use(isAuthed)`, `subscribedProcedure` adds `isSubscribed`. Onboarding/tour procedures stay `protectedProcedure` (must work pre-subscription — Lesson L2 deadlock).
  - **i18n:** `next-intl` `[locale]` routing; messages in `apps/web/src/i18n/langs/{fr,en}.json`; proxy handles locale BEFORE auth guards.
  - **Theme:** shadcn/ui + Tailwind 4 semantic tokens (`bg-background`, `text-foreground`, `border-border`, `bg-primary`) — current "Warm Linen" theme; do not hardcode legacy Vet Teal hex.
- ADRs in scope: **`docs/adr/0001-tour-engine.md`** (first-run guided tour engine — driver.js + custom cross-route controller; `User.tourCompletedAt` + `User.tourState`).

## Lessons applicable

- **L1 (Scope: apps/web hooks):** Zsa server actions return `[data, error]` tuples; TanStack `mutateAsync()` returns data directly. Destructure correctly per call site. (Caused a runtime `TypeError` in Epic 3.)
- **L2 (Scope: QA gate for multi-step flows):** Unit/integration tests don't replace real user-journey testing. Add E2E or scripted manual coverage for end-to-end flows before declaring done. (428 passing tests still let an onboarding deadlock through.)
- **L3 (Scope: review of architecture-contract stories):** Cross-reference implementation against the documented design (FR/NFR, auth strategy), not just code-level correctness.
- **L4 (Scope: implementation, third-party SDKs):** Consult up-to-date docs (Context7) for every SDK; record sources in Dev Notes. (Coding "from memory" surfaced outdated Stripe SDK patterns.) → Applies to **driver.js** in Story 10.4.
- **L5 (Scope: monorepo build, SWC-compiled type exports):** SWC builds emit no `.d.ts`; the `tsc --emitDeclarationOnly` pass in `apps/api` is load-bearing for `@pawly/api/trpc-types`.
